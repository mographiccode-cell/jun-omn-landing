# JUN - جمال عُمان | @jun.omn

![JUN Profile](https://www.instagram.com/jun.omn/media/?size=large)

**JUN (@jun.omn) - علامة جمالية ونمط حياة فاخرة من مسقط، عُمان. بواسطة جهناء حمود.**

## نظرة عامة

JUN هو موقع رسمي للعلامة التجارية JUN (@jun.omn)، تم بناؤه باستخدام أحدث تقنيات الويب. يعكس الموقع الهوية البصرية الحقيقية للعلامة ويوفر تجربة مستخدم احترافية وسلسة.

## الميزات

### التصميم الاحترافي
- **اللغة:** العربية بالكامل مع دعم RTL
- **الاستجابة:** متجاوب بالكامل للهواتف المحمولة، الأجهزة اللوحية، وأجهزة الكمبيوتر
- **الأنيميشن:** حركات ناعمة واحترافية مع تأثيرات 3D
- **الرسومات:** تصميم فاخر وأنيق باستخدام Tailwind CSS

### الأداء والتحسين
- **سرعة التحميل:** محسنة مع تقليل حجم الملفات
- **SEO:** تحسينات أساسية لمحركات البحث
- **الأجهزة المحمولة:** تصميم مناسب للهواتف المحمولة أولًا
- **التوافق:** يعمل على جميع المتصفحات الحديثة

### المحتوى
- **الهوية البصرية:** تعكس هوية JUN الحقيقية
- **الألوان:** لوحة ألوان فاخرة (وردي ناعم، ذهبي، كريمي)
- **الخطوط:** خطوط أنيقة وعصرية
- **المحتوى:** محتوى أصيل من الحساب

## كيفية الاستخدام

### محليًا
1. قم باستخراج محتويات المستودع
2. افتح الملف `landing-page.html` في متصفح الويب
3. الموقع جاهز للاستخدام مباشرة

### عبر الإنترنت
قم بزيارة الموقع مباشرة:
**https://jun-omn.github.io/jun-omn-website**

## كيفية التحديث

### إضافة محتوى جديد
1. قم بتحديث ملفات البيانات في مجلد `data/`
2. أضف الصور إلى مجلد `images/` أو `videos/`
3. قم بتحديث ملف `brand-identity.json` إذا تغيرت الهوية البصرية
4. قم برفع التغييرات إلى المستودع

### نشر التحديثات
1. قم بعمل commit للتغييرات
2. قم بالرفع إلى المستودع
3. سيتم تفعيل GitHub Pages تلقائيًا
